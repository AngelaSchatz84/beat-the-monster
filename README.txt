BEAT THE MONSTER – Prototype 01: Ending Monster

Files:
- index.html
- ending-monster.png
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

This prototype contains:
- Start screen
- Monster World
- Ending Monster battle with 48 cards
- 10 monster lives
- Check answer / correct hit / wrong no-hit
- Automatic partner role switching
- Victory screen
- Local completion storage
- PWA manifest + offline cache

Important for iPad:
The full interactive PWA should be tested from a hosted HTTPS URL.
Opening index.html inside a file preview may not run JavaScript or service workers correctly.
